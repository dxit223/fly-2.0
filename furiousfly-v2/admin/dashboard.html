System Architecture Overview

Welcome to the Furious Fly administration portal. This client-side platform handles real-time data sync with `/index.html`, `/services.html`, `/blog.html`, and `/contact.html`.

By modifying the blogs, messages, or services inside this portal, you immediately update the state of the public website via localized sync tunnels. This architecture provides you with fully functional CMS capabilities before final deployment.
